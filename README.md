# The Legal Lens

A student-led legal career initiative.

## Publish with GitHub Pages

1. Create a GitHub account at https://github.com if you don't already have one.
2. Create a **new public repository** named `the-legal-lens`.
3. Upload every file in this folder to the repository root:
   - `index.html`
   - `interviews.html`
   - `lens-live.html`
   - `about.html`
   - `get-involved.html`
   - `style.css`
   - `script.js`
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will give you a live `github.io` address.

### Updating the site
Edit the HTML files directly in GitHub. The site automatically updates after the changes are published.

### Important
The email address and Instagram URL in the site are placeholders. Replace them with your actual project email and Instagram URL before publishing.

GitHub Pages is available with GitHub Free for public repositories. A custom domain is optional and can be added later.
